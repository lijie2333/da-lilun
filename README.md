# 大理论 Skill

> 都大理论时代了，你还没有自己的理论？

薄肌理论、大水理论、大睡理论、大便理论……2026 年，中国互联网进入了大理论时代。

**大理论**是一个 Claude Skill（给 AI 装的技能包）。它会问你三四个问题，从你每天都在做的一件小事里，给你造一个属于你自己的「大X理论」，最后交给你一段能直接发小红书、X 的推文短文。

理论可以不真，但一定要自圆其说。

## 它会给你什么

一段像这样的推文（节选，完整版见 [`references/范例.md`](references/范例.md)）：

```
为什么我劝所有打工人吃大锌

如果你还在靠第三杯冰美式续命，那我不要和你说话。

大锌理论 = 每天 1 片锌，配 1.5L 大水。

你以为是心累，其实是锌少。

锌参与人体三百多种酶的工作。
你熬的每一个夜，都是拉着三百多个打工酶陪你加班。

咖啡是借精力，锌是存精力。
借的要还，一般在第二天下午三点还。

弱者靠咖啡续命，强者靠大锌回血。
```

## 安装

**Claude Code**：把这个仓库克隆到技能目录。

```bash
git clone https://github.com/lijie2333/da-lilun.git ~/.claude/skills/da-lilun
```

**Claude 网页版 / 桌面版**：到 [Releases](https://github.com/lijie2333/da-lilun/releases) 下载 `da-lilun.skill`，在设置的技能（Skills）里上传。

## 怎么用

对 Claude 说「给我造个大理论」，或者输入 `/da-lilun`。然后回答几个问题：

1. 你每天雷打不动要做的一件小事是什么？
2. 你做这件事，是想对付自己的什么状态？
3. 多久一次、用多少？

答完它就开始立论。不想答的题说「跳过」就行。

## 它是怎么造的

公式：**大X理论 = 一群人的处境 + 一件便宜的、自己说了算的小事 X + 它顶替掉的那个被高估的 Y。**

大水顶替奶茶，大睡顶替熬夜假装努力。房价、工作、前途你管不了，但今天喝几升水、几点睡，你自己说了算。

写的时候「前一步真，后一步歪」：先摆一条站得住的根据（比如锌真的参与三百多种酶的工作），再歪推一步，接到这群人的日常里。整套方法和真实案例在 [`references/`](references/)：

- `方法论.md`：这类理论为什么火、造的步骤、可信度工具箱
- `案例库.md`：网上真实流传的大字头理论和网友的玩法，也用来避免撞名
- `范例.md`：一次完整的真实测试，包括一次走偏和纠正

## 边界

- 纯属娱乐的荒诞创作，不是健康或人生建议。涉及吃喝、睡觉、运动的理论，会在末尾加一行「身体的事听医生的」。
- 不碰政治，不拿性别、地域、职业群体当宿敌，不拿真人隐私开玩笑。
- 不替真实存在的机构、期刊、专家编造数据和原话。
