# 怎么造一个大理论

调研日期 2026-10-10 至 10-11，来源见 `案例库.md`。

## 为什么这类理论会火（造的时候要戳中的东西）

1. **用一件小事顶替一个被高估的东西。** 大水顶替饮料，大睡顶替熬夜表演，大走顶替刷手机，大菜顶替网红餐厅。被顶替的 Y 往往是上一个时代的「标准答案」：消费升级、奋斗、精致、向上社交。小红书「詹说」的总结：年轻人在重新审视那些曾经被社会赋予高价值的东西。
2. **大事管不了，小事自己说了算。** 房价、工作、前途不由自己定，喝多少水、几点睡自己能定。可以完成的小行动给人「自我效能感」，也就是相信自己还能办成点事。
3. **三种廉价。** 不花钱、不花时间、不费感情。知乎高赞：「不只是金钱上廉价，还有时间上廉价和感情上廉价。」
4. **把「不得不」说成「我选的」。** 喝不起饮料，说成强者喝大水；退出竞争，说成纯过日子。
5. **在最小的事上宣布胜利。** 知乎高赞：「你能买瓶大水喝你就赢了。」
6. **「理论」两个字让一句生活建议有了体系，也有了身份。** 小红书评论：「迎来了『理论』一词含金量的大降级时代。」用户就是在享受这种降级。
7. **一半当真，一半玩梗。** 信的人和笑的人都能参与。

## 内部逻辑：造的步骤（不展示给用户，用来写出那段推文）

1. **定人群和处境。** 这段推文写给谁（打工人、考研党、健身的人……），戳他们哪一个具体时刻。写得越具体，读的人越觉得「这说的就是我」。例：「下午三点，文档开着，眼睛睁着，脑子不在。」
2. **定 X。** 用户每天做的那件小事。好的 X：几乎不花钱，自己说了算，能拍成一个动作。
3. **定 Y。** 从处境里找：这群人现在靠什么硬撑这个处境？Y 最好是一种消费、一种忙碌、一种表演（第三杯冰美式、熬夜、网红餐厅）。不要从字面上的「替代品」里找。
4. **起名。** 大 + X 的一个字。先查案例库，已经有的不用；撞了就换同义的单字或更具体的字（泡脚 → 大泡）。「大」字头不能丢，它是让人一眼认出「又一个大字头理论」的标记。
5. **定标准。** 带精确数字：「每天 1 片锌，配 1.5L 大水」「每天 3 个鸡蛋」。
6. **口号。** 「弱者 Y，强者大X。」Y 写具体的东西（「弱者灌冰美式」，不写「弱者消费」）。
7. **找根据。** X 真实的作用是什么：营养学、生理学、心理学里确有把握的常识。这是地基，读的人挑不出毛病，后面的歪推才站得住。拿不准就查证，查不到就不用。
8. **接到人群上。** 每条根据都落到这群人的日常里。例：「锌参与人体三百多种酶的工作」→「你熬的每一个夜，都是拉着三百多个打工酶陪你加班」。这一步是笑点所在。
9. **吸收反驳。** 想两三个最可能的质疑，每个都转成本理论的证据：「没感觉就对了，大锌是底层系统更新，不弹通知。」
10. **加调料。** 从下面的工具箱里挑合适的，有就用，没有不硬凑。

## 可信度工具箱

原则：前一步真，后一步歪。先摆一个站得住的东西，再歪推一步。前一步越真，后一步越好笑。

| 工具 | 怎么用 | 例子 |
|---|---|---|
| 真根据，歪推理（主力） | 摆一条真实的作用或常识，推出离谱但顺耳的结论 | 「锌参与人体三百多种酶的工作。补锌，就是给体内三百个打工人发工资。」 |
| 让读者自证 | 用一个场景或反问，让读者拿自己的经历作证 | 「下午三点，文档开着，眼睛睁着，脑子不在。那不是你不努力，是你的锌力下线了。」 |
| 算账 | 用日常价格和时间算一笔账，数字必须算对，写明按什么价算 | 「一杯冰美式 9.9，一片锌 5 毛。」 |
| 吸收反驳 | 每个质疑都转成本理论的证据 | 「咖啡是借精力，锌是存精力。借的要还，一般在第二天下午三点还。」 |
| 谐音 | 名字里的字和常用词同音，就顺势用 | 「锌」「心」「薪」：「心力交瘁，本质是锌力交瘁」「大锌 ＞ 大薪」 |
| 套物理定律 | 照着牛顿定律、公式的格式写 | 「每一个熬过的夜，都会在第二天下午三点产生一个大小相等、方向相反的困。」「产出 = 努力 × 锌」 |
| 倍增器 / 底座 | 宣布自己不和其他大理论抢地盘，而是让它们生效的前提 | 「大水 × 大锌，喝的每一口都算数。大锌不是又一个大理论，是所有大理论的底座。」 |
| 借前辈 | 用已经火了的理论当靶子或盟友 | 「所有理论都可以表演，只有拉屎没法摆拍。」（大史理论） |
| 真典故（可选） | 有现成贴切的才用，只用公认的史实、诗词、俗语，不编原话，不硬攀 | 「明清科举考场有『出恭入敬』牌，考生要先领牌才能如厕。」 |
| 精确数字 | 标准用精确数字；统计类数字拿不出真实出处，只能挂在一眼假的机构下 | 「大理论研究院对 37 名网友的追踪显示，81.3% 的人……」 |

不能用的：给真实存在的机构、期刊、专家、指南编造条款、数据或原话。荒诞要一眼可辨，不能让截图离开上下文以后变成一条谣言。

## 产出前自查

- 推文里有没有出现内部逻辑的痕迹：「论据一」、小标题、「三定律」字样？有就改回说话的样子。
- 截出任意三行，没看过上下文的人能不能看懂、会不会笑？
- 根据是不是都站得住？账有没有算对？
- 人群和处境是不是具体到一个时刻？
- 名字有没有和已有理论撞名？
- 宿敌有没有滑到性别、地域、职业群体上？
